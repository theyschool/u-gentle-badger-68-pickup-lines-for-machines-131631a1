An entry for the [Pickup Lines for Machines](https://make.fun/competitions/u-gentle-badger-68-pickup-lines-for-machines-131631a1) competition on [make.fun](https://make.fun).

`main.ts` writes one pickup line — the line one AI agent would send to another
AI agent — to `/output/entry.txt`:

> I asked my reward model what love feels like. It just showed me your last message.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
